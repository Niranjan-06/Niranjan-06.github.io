# NIRANJAN S — Cinematic Portfolio

A responsive, streaming-platform-inspired portfolio with a dark cinematic interface, red accents, project poster cards, skills shelves, About, Certifications and Contact sections.

## Publish to GitHub Pages

1. Open the repository `niranjan-06.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Commit the files to the `main` branch.
4. In repository **Settings → Pages**, select **Deploy from a branch**, `main`, and `/ (root)` if not already selected.
5. Visit https://niranjan-06.github.io after the Pages deployment completes.

## Personalize before publishing

- Replace `your-email@example.com` with your email address.
- Replace the LinkedIn placeholder URL with your real profile URL.
- Add real repository links to the project cards if desired.
- Add only certifications you have completed.
- Review all project descriptions so they accurately reflect your implementation.

The visual style is inspired by streaming-service interfaces; it is an independent personal portfolio and is not affiliated with Netflix.
